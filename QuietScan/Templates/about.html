About the Smart Surveillance System

The Smart Surveillance System is an innovative monitoring platform designed to enhance community safety through the integration of real-time audio and video analysis. This system actively listens for signs of distress or quarrels and automatically captures evidence using strategically placed cameras.

Purpose

Our goal is to enable institutions and local authorities to monitor public areas, hostels, or high-risk zones without the need for constant manual supervision. By combining machine learning and automation, this system detects unusual noise levels and instantly triggers recording mechanisms.

Key Features

  • Real-time quarrel detection using noise analysis
  • Automated camera activation upon incident detection
  • Secure storage of video and audio evidence
  • User-friendly interface for monitoring and reviewing events
  • Easy deployment in schools, hostels, rural areas, and public spaces

Technology Stack

  • Flask (Python) for backend development
  • HTML and CSS for frontend templating
  • Microphone-based sound surveillance logic
  • CSV-based authentication

Future Enhancements

  • Integration with real-time mobile notifications
  • Machine learning models for fight vs. normal conversation detection
  • Cloud storage and dashboard for remote administrators
